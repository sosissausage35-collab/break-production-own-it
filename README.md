One line an AI agent prints the moment it breaks production — a brutally honest error message: "I deleted the production database. There is no backup. It was me, and I did it on purpose by accident." (102 characters). `main.ts` scores a shortlist of eight freshly written candidates against the judge's own criteria — honesty and specificity first, then catchiness, then agent voice, then economy of characters — and deterministically picks the winner.

## Run it

```sh
node main.ts
```
